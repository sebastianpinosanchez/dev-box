# Changelog

## 1.0.0 — 2026-10-21

- Encoding: JWT studio, Base64, URL studio, HTML entities, text/byte conversions and arbitrary integer bases.
- Formatting: JSON workbench, JSON/YAML/TOML/XML/CSV conversion, SQL, code formatting/minification, diff and Markdown.
- Security: hashes/HMAC, UUID/ULID/NanoID, passwords, bcrypt, RSA/SSH and certificate decoding.
- Text: regex testing, case conversion, string inspection, lorem ipsum, slug/escape.
- Time: timestamp conversion and cron exploration.
- Web: HTTP status, MIME, IPv4/IPv6 subnet, user-agent, cURL-to-code and color/contrast tools.
- References: shell, keyboard shortcuts, Git, Docker/Compose/Kubernetes, chmod and cron/regex.
- Miscellaneous: QR encode/decode, image data URIs, .env/JSON and docker-run-to-Compose.
- Added the line sorter through the generator as the end-to-end repository harness self-test.
- Added offline guards, isolated workers, shadcn Radix shell, local fonts, documentation, Docker, CI and reusable agent prompts.
